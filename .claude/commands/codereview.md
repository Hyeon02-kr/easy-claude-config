\# 코드 리뷰

다음 규칙에 따라 코드를 리뷰하시오:

* CLAUDE.md 또는 PLAN.md 파일을 읽고서 프로젝트 개발의 진행순서(Phase)들을 확인한다.
* docs/report 폴더 내의 문서들을 읽고 현재까지 진행된 내용을 파악한다.
* 프로젝트 폴더 구조를 확인하여 현재 진행된 내용들이 정상적인지 확인한다.
* 프로젝트 내부 파일들을 확인하여 실제 개발이 정상적으로 이뤄졌는지 점검한다.

  * 사용자에게 최근 진행된 Phase 정보를 받았을 경우, 해당 Phase에 수정이 이루어진 파일들만 검사한다.
  * 사용자가 특정 Phase들을 언급하였을 경우, 해당 Phase들과 관련된 파일들을 검사한다.
  * 사용자가 Phase를 언급하지 않은 경우, 모든 파일들을 검사한다.
  * docs 폴더 내의 문서들은 검사 대상에서 제외한다.
* 수정이 필요한 부분과 계획과 다른 부분, 발견된 취약점 등을 사용자에게 정리하여 안내한다.
* 리뷰 중 파일 추가/수정/제거는 금지한다.
